# Group8 -- Assignment 3

### This readme applies for assignment 3.1

In order to run the first part of the assignment, you should have Docker installed and up running.

Once you have Docker up and running, run the command

```
docker compose up
```

Once the entire system is running, you can send POST request under the baseurl `http://127.0.0.1:8080` for both authentication and URL shortener service.
